📈 Instagram Follower Tracker

Upload or drag and drop two follower files to see who unfollowed you.

How to get your followers list:
1. Open Instagram on your computer.
2. Go to your profile → Followers.
3. Scroll all the way to the bottom.
4. Press F12 (or Fn + F12) and open the Console tab.
5. If allow pasting doesn't work at first, type any letter (like a) once, then type allow pasting and press Enter.
6. Paste the script below and press Enter.
7. A file named followers.txt will be downloaded. Rename it to something like followers1.txt.
8. For the second time, Rename it followers2.txt, And drop them both below 👇 const dialog = document.querySelector('[role="dialog"]'); if (!dialog) { alert('Open your Followers popup first.'); } else { const usernames = [...dialog.querySelectorAll('a')] .map(a => a.textContent.trim()) .filter(text => text.length > 0 && !text.includes(' ') && /^[A-Za-z0-9._]+$/.test(text) ); const unique = [...new Set(usernames)].sort(); const blob = new Blob([unique.join('\n')], { type: 'text/plain' }); const link = document.createElement('a'); link.href = URL.createObjectURL(blob); link.download = 'followers.txt'; link.click(); }
